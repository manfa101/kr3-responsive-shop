# Отчёт Lighthouse

Сюда кладётся скриншот проверки Lighthouse (категория Accessibility):

- `accessibility-report.png` — `index.html`;
- `accessibility-report-catalog.png` — `catalog.html`;
- `accessibility-report-order.png` — `order.html`.

Проверка делается в Chrome: DevTools (F12) → вкладка Lighthouse → Accessibility → Analyze page load.
